# archfetch 🏔️

Минималистичная и быстрая утилита отображения системной информации для Arch Linux, написанная на чистом C без сторонних зависимостей.

## 🎯 Цели проекта
- Изучение системного программирования на C в Linux.
- Чтение и парсинг данных напрямую из `/proc` и `/sys`.
- Оптимизация работы с памятью и строками.

## 🚀 Функционал (В разработке)
- [ ] Название ОС и версия ядра
- [ ] Время работы системы (Uptime)
- [ ] Потребление оперативной памяти (RAM)
- [ ] Модель процессора (CPU)
- [ ] Цветной вывод в терминал (ANSI escape codes)

## 🛠️ Сборка и запуск
```bash
$ gcc -Wall -Wextra -std=c11 src/main.c -o archfetch
$ ./archfetch
